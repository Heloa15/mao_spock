# 🎮 Pedra, Papel, Tesoura, Lagarto e Spock

Um jogo interativo inspirado na versão famosa apresentada em **The Big Bang Theory**, desenvolvido com **HTML, CSS e JavaScript**.

O jogador escolhe uma carta e enfrenta o computador em partidas rápidas com visual neon e interface estilizada.

---



### 🎯 Funcionalidades

✅ Escolha entre **5 cartas**  
✅ Computador joga aleatoriamente  
✅ Resultado aparece no centro da tela  
✅ Placar em tempo real  
✅ Cartas com cores neon diferentes  
✅ Modal com regras do jogo  
✅ Interface estilizada e responsiva  

---

## 🕹️ Como jogar

Escolha uma das cartas:

✂️ Tesoura  
🦎 Lagarto  
🪨 Pedra  
🖖 Spock  
📄 Papel  

O computador escolhe outra carta aleatoriamente.

Depois o jogo verifica quem venceu.

---

## 📖 Regras

✂️ Tesoura corta Papel  
📄 Papel cobre Pedra  
🪨 Pedra quebra Tesoura  

🦎 Lagarto envenena Spock  
🖖 Spock quebra Tesoura  

✂️ Tesoura decapita Lagarto  
🦎 Lagarto come Papel  

📄 Papel refuta Spock  
🖖 Spock vaporiza Pedra  

🪨 Pedra esmaga Lagarto
